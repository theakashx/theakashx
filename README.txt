AKASH PORTFOLIO
===============

Open index.html in any browser to see the site. It is one self-contained file
(photos are built in). Fonts load from Google Fonts, so you need internet for them.

PUT IT ONLINE FOR FREE
- Netlify: go to app.netlify.com/drop and drag this folder in.
- Vercel or GitHub Pages also work: upload index.html as the site's main file.
- Later, point your own domain (yourname.com) at it from the host's settings.

EDIT YOUR DETAILS (open index.html in a text editor, search for "CONFIG")
- EMAIL: your email address, used by the "Copy my email" button
- SOCIALS: add a url for each account you want switched on
- PROJECTS: replace the sample projects with your real ones
- Page text: the bio, skills, timeline and post titles are plain text in the file

SECRETS
- Type "sleep" on the page, or tap the star at the bottom 3 times, for a game.
